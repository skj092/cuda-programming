## Problem generated by claude:

Beginner Level Problems:

1. Vector Addition
- Challenge: Write a CUDA program to add two vectors of 1 million elements
- Learning goals: Basic kernel writing, memory allocation, and transfer
- Extra: Time your GPU implementation vs CPU implementation

2. Element-wise Matrix Operations
- Challenge: Perform element-wise multiplication of two 1024x1024 matrices
- Learning goals: 2D thread indexing, handling larger datasets
- Extra: Add support for different matrix sizes

3. Array Reduction
- Challenge: Find the sum of all elements in an array of 1 million numbers
- Learning goals: Understanding parallel reduction, shared memory usage
- Extra: Try different reduction techniques

Intermediate Level:

4. Matrix Multiplication (when you're ready)
- Challenge: Multiply two 1024x1024 matrices
- Learning goals: More complex memory access patterns, tiling
- Extra: Implement different optimization techniques

5. Image Processing
- Challenge: Implement a 3x3 convolution filter on a grayscale image
- Learning goals: Handling boundary conditions, shared memory optimization
- Extra: Support different kernel sizes

These problems are ordered to help you gradually learn key CUDA concepts:
- Memory management
- Thread/block organization
- Shared memory usage
- Performance optimization
- Memory access patterns
